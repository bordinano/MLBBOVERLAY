# MLBB Overlay

A customized **Mobile Legends: Bang Bang (MLBB) overlay** designed for tournament and broadcast use.

This project is a modified/customized version of the **False MLBB Overlay**, with additional features and adjustments made for a more flexible MLBB production workflow.

## ✨ Features

* 🎮 MLBB match overlay
* 🏆 Team and player information
* 📊 Customizable match information
* 🎨 Customized overlay design
* 🔄 Real-time match information
* 🖥️ Designed for broadcast/streaming setups
* ⚙️ Custom configuration and controls
* 🎥 Suitable for tournament production and livestreaming

## 🛠️ Purpose

This project is intended to provide a **customized MLBB overlay** for personal, tournament, and broadcast production use.

The goal is to improve the default False MLBB Overlay by adding custom features, modifying the interface, and adapting it to specific production requirements.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/bordinano/MLBBOVERLAY.git
```

Navigate to the project directory:

```bash
cd MLBBOVERLAY
```

Install the required dependencies according to the project's setup instructions.

## ⚙️ Configuration

Configure the overlay according to your production setup.

Configuration files and available options will be documented as the project develops.

## 🎥 Usage

Launch the overlay and configure the required match information.

The overlay can then be used as a browser/overlay source in broadcasting software such as:

* OBS Studio
* vMix
* Streamlabs
